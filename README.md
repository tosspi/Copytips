# Copytips
Windows小软件，当复制文字时屏幕出现弹窗提醒

<img width="790" alt="改造前后对比" src="before-after.png" />

Copytips —— 极简剪贴板提示器  
一句话总结：  
**“复制即提示，不打扰，看得见。”**

具体效果一览：  
1. **实时监听**  只要有文本被复制（Ctrl+C），立即在屏幕底部中央弹出 **深色圆角胶囊“✓ Copied”** 提示。  
2. **圆角 + 柔和投影**  逐像素 Alpha 渲染的圆角胶囊（可见区约 93×32），深浅壁纸下都清晰，边缘平滑无锯齿。  
3. **固定位置**  不跟随鼠标，始终位于任务栏上方 16 px、水平居中，2 秒后自动消失；连续复制只刷新同一个提示，不会叠出多个。  
4. **零打扰**  无焦点、无声音、鼠标点击可穿透，不中断当前操作。  
5. **托盘控制**  托盘图标右键可“开机自启 / 退出”。  
6. **零依赖**  单文件约 25 KB，拷到 Win10/11 即可双击运行。

   
一句话：复制即提示，从不打扰。

--------------------------------------------------
1. 它能做什么  
- 监听系统剪贴板，只要检测到 **纯文本复制** → 立即在屏幕底部中央弹出 **“Copied”** 提示  
- 2 秒后自动消失，全程无焦点、无声音  
- 托盘右键可 **开机自启 / 退出**  

--------------------------------------------------
2. 视觉特点  
- **深色半透明圆角胶囊**（#202128，约 66% 不透明度）+ 13% 白色内描边 + 柔和投影  
- **翠绿对勾 + 白色 “Copied”**，Segoe UI Semibold 13px，按 DPI 缩放；文字满不透明，主体半透明也不牺牲可读性  
- 尺寸紧凑（窗口约 107×46，胶囊约 93×32），固定在任务栏上方 16 px，不跟随鼠标，**不遮挡任务栏**（任务栏自动隐藏时按任务栏真实位置避让）  

--------------------------------------------------
3. 体积 & 依赖  
- **单文件约 25 KB**  
- **零依赖**：拷到任何 Win10/11 电脑直接双击即用  
- **零配置**：不写配置文件，只用注册表存“是否开机自启”  

--------------------------------------------------
4. 版本号规则  
采用 `主版本.次版本.修订号`（SemVer 2.0.0），版本号只在 `version.h` 一处维护，源码与资源文件都从它读取：

| 段位 | 何时递增 | 例子 |
|---|---|---|
| **主版本** | 用户可感知的行为或形态大改，旧观感/用法不再成立 | 方窗 → 圆角胶囊 |
| **次版本** | 视觉风格或新能力调整，用法完全兼容 | 更小 + 半透明 |
| **修订号** | 只修 bug / 只调参数，不改外观也不改行为 | 修正描边亮度 |

**每次改动都必须至少递增其中一段，不允许改了代码却不改版本号。** 版本号会出现在文件属性（右键 → 详细信息）和托盘图标的悬停提示里。

| 版本 | 变化 |
|---|---|
| 2.1.1 | 修复弹窗压住任务栏：任务栏自动隐藏时 `SPI_GETWORKAREA` 返回整屏，改用 `Shell_TrayWnd` 真实矩形取安全线；与任务栏间距 8 → 16 px |
| 2.1.0 | 胶囊 113×40 → 93×32，字号 16 → 13px；主体不透明度 90% → 66%；托盘图标圆角改为独立参数 |
| 2.0.0 | 方窗 260×90 → 圆角胶囊；单窗口复用、逐像素 alpha、工作集 12.0 → 9.9 MB |
| 1.0.0 | 初版：260×90 方窗，整窗统一 20% 不透明 |
