**“复制即提示，不打扰，看得见。”**

**下载**：前往 [Releases](https://github.com/tosspi/Copytips/releases/latest) 下载 `copytips.exe`（约 115 KB，免安装，Win10/11 x64），双击即用。

具体效果一览：  
1. **实时监听**  只要有文本被复制（Ctrl+C），立即在屏幕底部中央弹出 **深色圆角胶囊“✓ Copied”** 提示。  
2. **圆角 + 柔和投影**  逐像素 Alpha 渲染的圆角胶囊（可见区约 93×32），深浅壁纸下都清晰，边缘平滑无锯齿。  
3. **固定位置**  不跟随鼠标，始终位于任务栏上方 16 px、水平居中，2 秒后自动消失；连续复制只刷新同一个提示，不会叠出多个。  
4. **零打扰**  无焦点、无声音、鼠标点击可穿透，不中断当前操作。  
5. **托盘控制**  托盘图标右键可“开机自启 / 退出”。  
6. **零依赖**  单文件约 115 KB，拷到 Win10/11 即可双击运行。

   
一句话：复制即提示，从不打扰。

--------------------------------------------------
1. 它能做什么  
- 监听系统剪贴板，只要检测到 **纯文本复制** → 立即在屏幕底部中央弹出 **“Copied”** 提示  
- 判定口径 **只认复制动作**：`Ctrl+C` / `Ctrl+X` / `Ctrl+Insert` / `Shift+Delete`，以及**右键菜单里的“复制”**（右键抬起后 2.5 秒内的写入即算）；仅选中文字（如终端“选中即复制”）、后台程序的程序化写入都不提示  
- 2 秒后自动消失，全程无焦点、无声音  
- 托盘右键可 **开机自启 / 退出**  

--------------------------------------------------
2. 视觉特点  
- **深色半透明圆角胶囊**（#202128，约 66% 不透明度）+ 13% 白色内描边 + 柔和投影  
- **翠绿对勾 + 白色 “Copied”**，Segoe UI Semibold 13px，按 DPI 缩放；文字满不透明，主体半透明也不牺牲可读性  
- 尺寸紧凑（窗口约 107×46，胶囊约 93×32），固定在任务栏上方 16 px，不跟随鼠标，**不遮挡任务栏**（任务栏自动隐藏时按任务栏真实位置避让）  

--------------------------------------------------
3. 体积 & 依赖  
- **单文件约 115 KB**（`/MT` 静态链接，无运行库依赖）  
- **零依赖**：拷到任何 Win10/11 电脑直接双击即用  
- **零配置**：不写配置文件，只用注册表存“是否开机自启”  
- **常驻开销**：40 ms 一次的组合键轮询（几次 API 调用，微秒级），用于管理员权限窗口里也能感知复制

4. 版本号规则  
采用 `主版本.次版本.修订号`（SemVer 2.0.0），版本号只在 `version.h` 一处维护，源码与资源文件都从它读取：

| 段位 | 何时递增 | 例子 |
|---|---|---|
| **主版本** | 用户可感知的行为或形态大改，旧观感/用法不再成立 | 方窗 → 圆角胶囊 |
| **次版本** | 视觉风格或新能力调整，用法完全兼容 | 更小 + 半透明 |
| **修订号** | 只修 bug / 只调参数，不改外观也不改行为 | 修正描边亮度 |

**每次改动都必须至少递增其中一段，不允许改了代码却不改版本号。** 版本号会出现在文件属性（右键 → 详细信息）和托盘图标的悬停提示里。

| 版本 | 变化 |
|---|---|
| 2.2.0 | 补齐三个场景：右键菜单“复制”也会提示（鼠标钩子记录右键抬起时刻，覆盖传统与自绘菜单）；管理员权限窗口里复制也能提示（40 ms 轮询 `GetAsyncKeyState` 兜底 UIPI）；误报面收窄（复制窗口 1500 → 400 ms、远程桌面自适应放宽，并新增“写入者必须是前台进程”校验） |

| 2.1.1 | 修复弹窗压住任务栏：任务栏自动隐藏时 `SPI_GETWORKAREA` 返回整屏，改用 `Shell_TrayWnd` 真实矩形取安全线；与任务栏间距 8 → 16 px |
| 2.1.0 | 胶囊 113×40 → 93×32，字号 16 → 13px；主体不透明度 90% → 66%；托盘图标圆角改为独立参数 |

7. 已知限制（2.2.0 起）  
- **程序化复制不提示**：`Set-Clipboard` 等脚本写入、应用内自绘的「复制」按钮不属于用户触发的复制动作，不提示。  
- **极短的按键可能漏检**：管理员权限窗口里的复制靠 40 ms 轮询兜底，按键短于一个采样周期时可能抓不到（正常人手按键远长于此）。  
- **右键抬起后 2.5 秒内的写入会被当成复制**：若右键点开菜单后选了别的项，而恰好这段时间内有程序写入剪贴板，可能误弹一次。  
- **残余误报窗**：按下复制键但目标程序其实没复制（例如焦点在图片或空白处）时，400 ms 内的写入仍可能被误认。已用「写入者必须是前台进程」过滤掉云剪贴板同步、输入法、剪贴板管理器这类后台写入；远程桌面下窗口放宽到 1500 ms（`INTENT_WINDOW_RDP_MS`）。  
- **经代理进程写剪贴板的程序可能不提示**：少数程序（部分 UWP 应用）不是由自己的前台进程写剪贴板，会被「写入者必须是前台进程」这一条判为后台写入。
