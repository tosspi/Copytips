# Copytips
Windows小软件，当复制文字时屏幕出现弹窗提醒

<img width="790" alt="改造前后对比" src="before-after.png" />

Copytips —— 极简剪贴板提示器  
一句话总结：  
**“复制即提示，不打扰，看得见。”**

具体效果一览：  
1. **实时监听**  只要有文本被复制（Ctrl+C），立即在屏幕底部中央弹出 **深色圆角胶囊“✓ Copied”** 提示。  
2. **圆角 + 柔和投影**  逐像素 Alpha 渲染的圆角胶囊（约 110×40），深浅壁纸下都清晰，边缘平滑无锯齿。  
3. **固定位置**  不跟随鼠标，始终位于任务栏上方 10 px、水平居中，2 秒后自动消失；连续复制只刷新同一个提示，不会叠出多个。  
4. **零打扰**  无焦点、无声音、鼠标点击可穿透，不中断当前操作。  
5. **托盘控制**  托盘图标右键可“开机自启 / 退出”。  
6. **零依赖**  单文件 < 120 KB，拷到 Win10/11 即可双击运行。

   
一句话：复制即提示，从不打扰。

--------------------------------------------------
1. 它能做什么  
- 监听系统剪贴板，只要检测到 **纯文本复制** → 立即在屏幕底部中央弹出 **“Copied”** 提示  
- 2 秒后自动消失，全程无焦点、无声音  
- 托盘右键可 **开机自启 / 退出**  

--------------------------------------------------
2. 视觉特点  
- **深色圆角胶囊**（#202128，约 90% 不透明度）+ 10% 白色内描边 + 柔和投影  
- **翠绿对勾 + 白色 “Copied”**，Segoe UI Semibold 16px，按 DPI 缩放，任何壁纸下都清晰可读  
- 尺寸紧凑（窗口约 131×58，胶囊约 113×40），固定位置，不跟随鼠标，**不遮挡任务栏**  

--------------------------------------------------
3. 体积 & 依赖  
- **单文件 < 120 KB**  
- **零依赖**：拷到任何 Win10/11 电脑直接双击即用  
- **零配置**：不写配置文件，只用注册表存“是否开机自启”  

--------------------------------------------------
4. 编译（一行命令）  
```cmd
rc copytips.rc
cl /EHsc /O2 /MT /DUNICODE /D_UNICODE copytips.cpp copytips.res user32.lib gdi32.lib shell32.lib advapi32.lib
```

--------------------------------------------------
5. 使用场景  
- 写代码 / 写文档 / 聊天时，想确认“我已经复制成功”  
- 录屏或直播时，观众也能看到复制提示  
- 远程桌面、虚拟机里同样可用  

--------------------------------------------------
一句话总结  
“复制即安心，提示不打扰”——Copytips 是你最轻量、最优雅的剪贴板小助手。
